# 🧱 03-建模

## 本目录存放什么

Blender 建模技术的核心笔记，是知识库的「主力」内容。

## 建议内容

- 多边形建模：基本体建模、挤出、环切、倒角、桥接
- 编辑模式操作：点/线/面三种选择模式、合并/分离、填充
- 修改器：细分曲面（Subdivision）、镜像（Mirror）、实体化（Solidify）等
- 曲线建模：贝塞尔曲线、文字、挤出到网格
- 硬表面建模：机械、道具类
- 有机建模：角色、生物（配合雕刻）
- 建模练习案例与思路

## 笔记命名规范

`03-建模/序号-名称.md`，例如 `01-编辑模式入门.md`、`02-常用修改器详解.md`

## 提示

每个建模技巧尽量配一张效果示意图（截图放进笔记或 `10-项目实战` 的对应项目里）。
