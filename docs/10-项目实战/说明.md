# 🛠️ 10-项目实战

## 本目录存放什么

按项目/练习案例积累的实操笔记——知识库「越用越厚」的关键。

## 组织方式

每个项目建立一个**子目录**，命名建议：

- `项目名/`（例如 `桌面场景/`、`木质水杯/`）
- 项目目录内包含：
  - `README.md` — 项目目标、参考图、完成度
  - `过程笔记.md` — 分步骤记录做了什么、踩了什么坑
  - `截图/` — 过程截图、成品图
  - `blend/`（可选）— 工程文件备份

## 项目选题参考（从易到难）

1. 简单物体：杯子、球体、书本
2. 组合场景：桌面场景、房间一角
3. 带材质灯光：完整渲染一张图
4. 低模游戏资产：道具、武器（含 UV 烘焙）
5. 角色/动画：简单角色绑定走路循环

## 笔记命名规范

每个项目子目录内，笔记用 `序号-名称.md`，例如 `01-建模阶段.md`、`02-材质与渲染.md`。
