# 🧠 01-基础概念

## 本目录存放什么

与具体软件无关的 3D 通用理论知识，是所有操作的「地基」。零基础建议从这里开始。

## 建议内容

- 3D 坐标系：XYZ 轴、单位、右手/左手坐标系
- 网格基础知识：顶点（Vertex）、边（Edge）、面（Face）、法线
- 拓扑：布线、多边形数量、四边形/三角形/多边形
- 变换：移动 / 旋转 / 缩放，物体的变换属性
- 渲染相关概念：PBR、光照模型、色彩空间、像素与分辨率
- 常见术语表：低模/高模、烘焙、UV、绑定、关键帧等

## 笔记命名规范

`01-基础概念/序号-名称.md`，例如 `01-什么是网格拓扑.md`、`02-坐标系与单位.md`
