# 🧠 拓扑（Topology）

在Blender（或任何多边形建模软件）中，**拓扑**这个概念听起来很技术，但你可以把它通俗地理解为：

**3D模型的“布线”或“网格结构”**——也就是构成模型的**顶点（点）、边（线）和面（块）**是如何排列和连接的。

如果说之前的“骨骼标志点”决定了模型**往哪长**，那么拓扑就决定了模型**怎么长**。我们用一个非常直观的例子来帮你建立概念：

## 1. 它为什么重要？（不仅仅是“好看”）

在雕刻时（如使用雕刻模式），拓扑可以很乱，因为软件只计算表面形状。但当你需要**做动画、绑骨骼、或放进游戏引擎**时，拓扑就是生死线：

- **为了变形（动画）**：人物眨眼、微笑、抬胳膊时，肌肉会拉伸。**好的拓扑**会让网格像皮肤一样顺着拉力方向伸缩；**坏的拓扑**则会导致模型在关节处像捏碎的纸团，出现尖锐的棱角或破洞。
- **为了光影（渲染）**：模型表面的高光和阴影是靠网格法线计算的。混乱的拓扑会让高光在脸上出现“马赛克”或“断崖”，导致皮肤油腻或脏乱。

## 2. 好拓扑的几条铁律

在Blender人物建模中，判断拓扑好不好，主要看这三条：

- **① 必须是“四边形（Quads）”为主**：尽量让每个面都是四条边。尽量避免三角形（Tris）和多边形（Ngons，即超过4条边）。因为四边形在细分和变形时最稳定，计算最平滑。
- **② 必须遵循“环形循环（Edge Loops）”**：线条要像跑道一样，绕着眼睛、嘴巴、肩膀、膝盖走**环形**。这样当角色做表情或弯曲关节时，褶皱会集中在环形圈内，不会扩散到整个脸或腿。
- **③ 极点（星点）要藏在“暗处”**：在四边形网格中，不可能全是规整的方块，必须要有“极点”（一个点连接3条或5条边）来转折布线。好的拓扑会把极点藏在**眼窝深处、嘴角后方、腋下、膝盖内侧**这些不太变形且不太显眼的地方。
- **④ 流向（Flow）要顺**：布线不只是「绕圈」，还要看**整体走向**。环线应该像水流一样顺着造型走，该收紧的地方收紧、该散开的地方散开。判断方法：沿一条环线走一遍，看它是「顺滑地前进」，还是在生硬地拐来拐去。

### 为什么偏偏是四边形？——网格的「对边结构」

三角形网格不是不能建模，而是它没有**对边（Opposite Edge）**：三角形里没有「隔着一条边的另一边」，线一走到三角形里就会撞上斜边、无路可走，环形线在这里断裂。四边形有天然的对边关系，环线才能一条压着一条、首尾贯通。

可以这么记：

- **四边形网格 = 一张规则织出来的布**：每个顶点连 4 条边，环线像布纹一样一路走到底；
- **极点 = 这块布的「针脚」**：它打破「每个顶点连 4 条边」的规则（变成 3 或 5 条），是所有转折、合并、加减环**必须付出的代价**。

所以不是「要避免极点」，而是「极点不可避免，只能管理」——这正是铁律③的真正含义。

## 3. 你可能会遇到的两个阶段

在Blender工作流中，拓扑通常分两个阶段：

- **雕刻阶段（忽略拓扑）**：用雕刻笔刷像捏泥巴一样堆出形状，这时网格很乱（动态拓扑），只追求**造型**。
- **重拓扑阶段（Retopology）**：在雕刻完高精度模型后，**必须**在它表面重新用规整的四边形“描”一遍新的低面数网格。Blender里的**收缩包装修改器（Shrinkwrap）** 和 **多边形建工具（Poly Build）** 就是专门干这个的。

## 4. 拓扑名词速查表（先混个脸熟）

理论名词很容易一听就忘，先混个脸熟：

| 名词 | 是什么 | 一句话直觉 |
| :--- | :--- | :--- |
| **顶点**（Vertex） | 网格里一个一个的「点」 | 网格的关节 |
| **边**（Edge） | 两个顶点之间的一条线段 | 网格的骨头 |
| **面**（Face） | 由边围成的一小块平面 | 网格的皮肤 |
| **环形线**（Edge Loop） | 首尾相接、绕一整圈的边串 | 关节上的橡皮筋 |
| **环带**（Edge Ring） | 与环形线垂直、并排的边串 | 垂直方向的轨道 |
| **极点**（Pole） | 一个点连着 3 条或 5 条边 | 布线的十字路口 |
| **三角面 / 多边形**（Tri / Ngon） | 3 条边 / 5 条边以上的面 | 能不用就不用 |
| **法线**（Normal） | 每个面「朝外」的方向 | 决定光影往哪走 |
| **非流形**（Non-Manifold） | 结构上「说不通」的网格 | 一定要修掉 |

> 顶点/边/面是永远在用的老三样；环形线、极点、三角面会在实操篇里反复出现；非流形是你要避开的地雷。

## 5. 细分：拓扑质量最直接的「照妖镜」

**细分（Subdivision）** 是建模里非常常用的工序：把网格切得更密、表面变得更光滑。它和拓扑的关系一句话就能说清——

> **细分不创造好拓扑，只暴露坏拓扑。**

- 拓扑好 → 细分后平滑、均匀，像一张被抚平的纸；
- 拓扑差（三角面扎堆、极点乱放）→ 细分后这里鼓包、那里凹陷，所有问题被成倍放大。

为什么细分能「照出原形」？细分不只是把面切碎，它还会**移动顶点把折痕抹平**。拓扑好的地方，顶点移动方向一致，表面越分越顺；拓扑乱的地方，每个顶点被相邻面「往不同方向拉」，于是这里鼓包、那里凹陷。毛病藏得再深，细分两三次也会被放大到肉眼可见。

这也是为什么很多建模是**先粗后细**：先用低面数把形状和布线定好，最后才加细分，让光滑交给细分来完成。细分背后的算法原理，见实操篇 [《布线详解》](../03-建模/03-布线详解.md) 的「细分的原理」一节。

## 6. 为什么拓扑影响光影？——法线与着色

渲染时，光影不是画上去的，而是靠网格表面的**法线（Normal）**算出来的：法线决定了每个点「朝外」的方向，光线按这个方向反弹，才有高光和阴影。

- **光滑着色（Shade Smooth）**：取相邻面的平均方向当顶点法线 → 表面看起来圆滑，没有棱线；
- **平面着色 / 硬边（Flat / Crease）**：每个面各自计算 → 棱角分明；
- **拓扑乱** → 相邻面的法线方向「各说各话」 → 高光在表面出现**断层、马赛克**，看起来脏或油腻。

补充机理：光滑着色并不是真的把表面磨圆，而是把**每个顶点的方向取相邻面的平均值**。三角面、狭长面让「相邻面」的方向天差地别，平均值就剧烈抖动——这也是为什么同样的形状，拓扑规整的地方光滑，拓扑乱的地方发灰、发脏。

所以「拓扑影响光影」的本质，是**法线方向的连续性**被拓扑决定了。想同时有「圆润的大面」和「分明的棱角」，光靠拓扑还不够，还要会管**着色方式**（平滑/硬边、折痕）。这属于材质与渲染的范畴，见 `05-材质与纹理` 和 `07-渲染`。

## 7. 非流形（Non-Manifold）——最隐蔽的拓扑地雷

**非流形（Non-Manifold）** 是指结构上「说不通」的网格，常见的形态有：

- 一条边同时被 3 个面共用；
- 两个面互相穿透、叠在一起；
- 网格里藏着多余的孤立顶点、悬空的边。

它为什么是地雷？细分会算乱、UV 展开会错位、3D 打印会失败、游戏引擎可能直接报错。**Blender 里检查**：编辑模式 → `选择` 菜单 → 按特征选择 → **非流形**，被高亮的区域就是要修的地方。

顺带一提，拓扑和 UV 是绑在一起的：UV 展开时的**接缝**最好放在环线、拐角或不显眼处，环线排得顺不顺，直接决定接缝好不好藏（UV 的完整知识在 `08-UV与烘焙`）。

## 8. 面数（Polycount）：网格的「计价单位」

聊模型一定绕不开**面数**——它决定了模型「贵不贵」。

- **低模 / 高模 / 中模**：同一个模型可以有不同密度的版本。高模细节全、面数高；低模结构简单、面数低；中模介于两者之间，常用来做过渡和变形。
- **计价单位是「三角面」**：引擎里模型最终都会被切成三角形来渲染（1 个四边形 = 2 个三角面），所以游戏里说面数，指的都是**三角面数**。
- **为什么要省面数**：面数越高，渲染、动画、加载越吃力；一个场景里几百上千个物体，每个省一点，整体就流畅一大截。
- **好拓扑为什么省面数**：细节能用环线表达的就别用面堆；面数低还不塌形，靠的就是「每一条边都花在刀刃上」。

> 🖼️ **法线贴图（Normal Map）的直觉**：低模表面平、面数低，但可以「穿一件贴图做的衣服」骗过光线——把高模表面的凹凸方向记进一张贴图，贴到低模上，灯光一打，低模看起来就有高模的细节。游戏里「低模 + 法线贴图 ≈ 高模」的原理就在这（完整烘焙流程见 `08-UV与烘焙`）。

## 9. 游戏 vs 影视：拓扑的两种世界观

拓扑的「好不好」，取决于你要把模型送进哪条流水线：

| | 游戏 | 影视 |
| :--- | :--- | :--- |
| 面数 | 预算紧张，越低越好 | 相对宽裕，追求细节 |
| 常用流程 | 低模为主，细节靠贴图 | 高模 + 细分 |
| 细节来源 | 法线贴图（烘焙） | 真实几何 |
| 最终形态 | 引擎会转成三角面 | 保持细分后的光滑面 |

但**共同点**是：四边面、环形线、极点这些「好拓扑」的基本功，两条路线的起点完全相同。区别只在后面怎么走——游戏的细节靠「烘焙法线贴图」（见 §8 的法线贴图直觉），影视则直接保留几何细节。

## 💡 给你的实操建议

初学者最容易犯的错就是**用雕刻的高模直接去绑定骨骼**。请记住这个流程：

> **雕刻（抓形） → 重拓扑（建规整布线） → 投影细节（烘焙法线贴图） → 绑定动画**

刚开始练拓扑，不用急着全身。你可以在Blender里打开一个球体，试着用**切刀工具（Knife）**和**挤出（Extrude）**，专门把球体的一半布线改成环绕“眼睛”和“嘴巴”的圈。把这一小块练会，你对“拓扑”的理解就超过一半初学者了。
