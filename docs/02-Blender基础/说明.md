# 🖥️ 02-Blender基础

## 本目录存放什么

Blender 软件本身的入门笔记：界面、操作、快捷键、设置。

## 建议内容

- 界面布局：各个编辑器（视图、属性、大纲、时间线等）
- 视图操作：旋转/平移/缩放视图、正交/透视切换、各种显示模式
- 基本操作：选择、移动/旋转/缩放、镜像、复制、删除
- 常用快捷键清单（也可放在 11-资源与参考 做速查表）
- 常用设置与优化：中文界面、显卡渲染设置、插件启用
- 文件管理：.blend 工程文件的保存与组织

## 笔记命名规范

`02-Blender基础/序号-名称.md`，例如 `01-界面布局详解.md`、`02-视图操作.md`

## 提示

笔记中涉及快捷键时，标注 Blender 版本（如 4.x），因为快捷键会随版本变化。
