# 法线贴图（Normal Map）

## 核心概念

法线贴图是一种纹理，用来在**低面数模型**上「骗」出**高面数细节**的光影效果。它不改变模型的几何形状，而是修改表面**法线的方向**，让渲染器在光照下以为表面有凹凸起伏，从而产生更丰富的阴影和高光细节。

**为什么重要**：游戏和实时渲染中不可能使用几百万面的高模。用「低模 + 法线贴图」就能以极低的性能成本，获得接近高模的光影效果——这是游戏资产制作的核心技巧。

> 简单记忆：几何决定模型的**轮廓**，法线贴图决定模型**表面光影的细节感**。

## 基础：法线到底是什么

在理解法线贴图之前，先搞清楚**法线（Normal）**本身。

- **法线**是垂直于模型表面的**方向向量**，它不表示位置，只表示「这个表面朝向哪个方向」。
- 方向向量用 `(X, Y, Z)` 三个数字表示，每个分量范围 `-1 ~ 1`。
- 每个面有一个**面法线**（Face Normal）；顶点上有**顶点法线**（Vertex Normal），是周围面法线的平均，用来让表面光影过渡平滑。
- 渲染器计算光照时，**法线方向直接决定表面的明暗**：
  - 表面正对光源 → 亮
  - 表面侧对光源 → 暗
  - 表面背对光源 → 全黑

> 🧭 简单理解：法线就像每块「瓷砖」朝向的指针。低模表面所有法线都是平的，所以光影平平；法线贴图修改了这些指针的朝向，光影就「看起来」凹凸不平了。

## 原理：为什么法线贴图是蓝紫色的

- **法线**是垂直于表面的方向向量 `(X, Y, Z)`，每个分量范围是 `-1 ~ 1`。
- 纹理的 RGB 颜色范围是 `0 ~ 1`，所以把法线向量映射到颜色：
  - `R = (X+1)/2`，`G = (Y+1)/2`，`B = (Z+1)/2`
- 大多数表面的法线朝外（指向 Z 正方向），所以 **B 通道最大** → 整体呈**蓝紫色**。
  - 完全平坦的表面法线是 `(0, 0, 1)` → 颜色 `(0.5, 0.5, 1)`，就是那种标准的蓝紫色。
  - 凸起处法线偏向外 → 颜色偏亮；凹陷处 → 颜色偏暗。
- **切线空间（Tangent Space）**：法线贴图记录的是「相对于表面」的法线方向，而非世界方向。因此同一张贴图可以贴到任何朝向、任何形状的模型上——这是最常用的法线贴图类型。

> 💡 看到蓝紫色的贴图基本就是法线贴图；如果贴图是灰白的，多半是**高度图/凹凸图**，不是法线贴图。

### RGB 三通道各代表什么方向

| 通道 | 对应方向 | 直觉 |
| --- | --- | --- |
| **R（红）** | 法线在 X 轴（左右）的偏转 | 表面朝向模型的左/右 |
| **G（绿）** | 法线在 Y 轴（上下）的偏转 | 表面朝向模型的上/下 |
| **B（蓝）** | 法线在 Z 轴（朝外）的偏转 | 表面朝向观察者/朝外 |

- 偏左偏右看 **R**，偏上偏下看 **G**，是否朝外看 **B**。
- 因为大多数表面朝外（B 最大），所以整体蓝紫色。
- 凹陷处法线朝内 → 蓝紫色变淡甚至发绿发红 → 光影上表现为「凹」。
- 凸起处法线偏外 → 蓝紫色更浓 → 光影上表现为「凸」。

### 法线贴图在光照中做什么

一句话版：**渲染时用「表面法线与光源方向」做点积运算，夹角决定明暗。**

- 法线与光源方向**夹角小**（正对光）→ 点积大 → 亮
- 法线与光源方向**夹角大**（侧对光）→ 点积小 → 暗
- 法线贴图修改了法线方向，就等于修改了每个像素的明暗结果 → 产生「假凹凸」的光影
- 这也解释了为什么法线贴图**不会改变模型的剪影轮廓**——轮廓由几何决定，法线只影响表面光影

### 切线空间 vs 对象空间

这是法线贴图最容易混淆的两个概念，务必分清楚。

### 切线空间（Tangent Space，也叫 TBN）

- 法线方向**相对于模型表面**记录：每个顶点有自己的切平面，由 T（切线）、B（副切线）、N（法线）三个轴构成，合称 **TBN 矩阵**。
- **优点**：贴图可复用——同一张贴图贴到任何朝向、任何相似形状的模型上都成立；模型变形、做动画、关节弯曲时，法线始终跟随表面，不会出错。
- **缺点**：渲染时需要引擎根据 UV 和顶点**重建切线**，实现稍复杂；UV 有拉伸、模型有硬边时可能出现接缝瑕疵。
- **适用**：游戏资产、角色、所有需要动画的模型——**绝大多数场景都用它**。

### 对象空间（Object Space）

- 法线方向**相对于物体的世界方向**记录，不依赖 UV。
- **优点**：无需重建切线，实现更简单；烘焙更快；对某些硬表面静态模型表现更精确。
- **缺点**：物体一旋转或变形，贴图方向就错了；贴图**不可复用**，换个模型必须重新烘焙。
- **适用**：完全静止的物体（静态建筑构件、单件展示道具）、静态扫描模型。

> 💡 默认全部用**切线空间**。只有确认模型完全静止、永不旋转变形时才考虑对象空间。

## 在 Blender 中如何使用

1. 选中模型，进入**材质属性**面板，找到 **Principled BSDF** 节点的 **Normal**（法线）输入口（橙色圆点）。
2. 添加一个 **Image Texture**（图像纹理）节点，加载法线贴图图片。
3. 通过一个 **Normal Map**（法线贴图）节点连接：`Image Texture → Normal Map → Principled BSDF 的 Normal 插口`。
4. ⚠️ **关键**：把 Image Texture 节点的**色彩空间（Color Space）设为 `Non-Color`（非颜色）**！法线是方向数据，不是颜色，否则颜色会被错误处理导致光影失真。

> 🚀 **Node Wrangler 插件**的 `Ctrl + Shift + T` 可以一键加载整套 PBR 贴图（Base Color、Roughness、Normal 等）并自动连好节点，法线会自动接到 Normal Map 节点上。详见 [02-Node Wrangler 插件详解](../11-资源与参考/02-Node Wrangler 插件详解.md)。

### 检查法线是否生效

- 连好节点后，从**侧面**打光，观察表面细节是否有立体感（正对光看不太出来）。
- 断开 Principled 的 Normal 输入，对比**有无法线**的光影差异——这是最直接的判断。
- 打开 **Material Preview（材质预览）** 模式，法线效果最直观。
- 视图叠加层里勾选 **Face Orientation**（面朝向），蓝色=朝外、红色=朝内，可辅助排查法线内外问题。

## 如何制作法线贴图

1. **烘焙（游戏资产最常用）**：高模 → 低模 + 法线贴图，详细流程见下一节。
2. **从高度图转换**：把黑白的高度图用工具（Substance、ArmorLab、在线转换工具）生成法线贴图。
3. **程序化生成**：用 Blender 的凹凸节点 + 高度图，或软件内置的纹理生成功能。

### Blender 烘焙实操步骤（从高模烘到低模）

**前提**：场景中有高模（细节丰富）和低模（最终展示的模型），低模已展好 UV。

1. **给低模展 UV**：选中低模 → 编辑模式展 UV（见 [01-展UV](../08-UV与烘焙/01-展UV.md)）。
2. **新建空图像**：在低模材质上添加 **Image Texture** 节点 → **新建**一张 `1024×1024`（或更高）的图像，准备接收烘焙结果。
3. **对齐模型**：给低模加 **Shrinkwrap（收缩包裹）修改器**，目标选高模，让低模贴合到高模表面；或手动把低模放到高模表面上方约 `1~2mm`（不要陷进去，避免穿帮）。
4. **选中顺序**：**先点选低模**（激活对象），再按住 `Shift` 加选高模——**低模必须是最后激活的橙色对象**。
5. **设置烘焙参数**：进入**渲染属性 → 烘焙（Bake）**面板：
   - **Bake Type（烘焙类型）**：`Normal`
   - **Space（空间）**：`Tangent`
   - **勾选 Selected to Active**：从高模烘焙到激活对象（低模）
   - **Extrusion（偏移）**：`0.01 ~ 0.1`，让采样略微偏出表面，防止自身遮挡误采
   - **Margin（边距）**：`2 ~ 8`，UV 岛边缘留边，减少接缝渗色
   - **Image**：选择第 2 步新建的图像
6. 点击 **Bake**，等待进度条完成。
7. **保存图像**：在图像编辑器里 `Alt + S` 另存为 PNG（建议 16 位）。

> ⚠️ 烘焙结果花屏、大片黑色或歪斜，多半是：低模没盖住高模、UV 有重叠、没勾 **Selected to Active**、或低模用了修改器但没应用。

### 从高度图（Height Map）生成法线

黑白高度图 → 法线贴图的原理是**用灰度梯度计算斜率**：

- 高度变化越陡，生成的法线偏转越大；平坦区域法线不变（保持蓝紫色）。
- 常用工具：Substance 3D 采样器、ArmorLab、在线转换器。
- 这种法线没有高模的细节精度，但足够为简单纹理提供「伪细节」，常用于石头墙、地面等。

## 关键参数

| 参数 | 说明 |
| ------ | ------ |
| **Strength（强度）** | Normal Map 节点的强度，默认 `1.0`。过大表面出现奇怪凹凸噪点，过小细节消失。 |
| **空间类型（Space）** | **Tangent（切线空间）**最常用，贴图通用；Object（对象空间）只适合单一固定物体。 |
| **DirectX vs OpenGL** | 两者的 **G 通道（绿色）方向相反**。导入引擎后凹凸方向反了，翻转绿色通道即可。 |
| **位深** | 烘焙建议用 **16 位 PNG** 保存，避免 8 位 JPG 的压缩色块让法线产生瑕疵。 |
| **Extrusion（烘焙偏移）** | 烘焙时采样偏出表面的距离，防止表面自身遮挡误采样，一般 `0.01 ~ 0.1`。 |
| **Margin（烘焙边距）** | UV 岛之间的留边像素，减少接缝渗色，一般 `2 ~ 8` 像素。 |

## 踩坑记录

- ❌ **忘了设 Non-Color**：法线贴图色彩空间还是 sRGB → 光影完全错乱、高光发花。
- ❌ **没用 Normal Map 节点**：把贴图直接连到 Principled 的 Normal 插口 → 方向数据被当成普通颜色，效果错误。
- ❌ **Strength 拉太高**：表面出现「起泡」般的伪高光。
- ❌ **烘焙时低模没完全盖住高模**：法线点指向错误方向，出现「穿帮」的凹陷。
- ❌ **UV 有重叠**：重叠区域的烘焙结果互相覆盖，出现撕裂状瑕疵。
- ❌ **用 JPG 存法线图**：压缩产生色块，细节区域全是噪点。
- ❌ **低模有修改器但没应用**：烘焙的是未细分的网格，导致错位。
- ❌ **忘了勾 Selected to Active**：烘焙出来是低模自身法线（全平，无细节）。
- ❌ **Margin = 0**：UV 岛之间没有边距，接缝处渗色、出现黑边。

## 常见误解澄清

- ❌ **「法线贴图能让模型真的凸起来」**：不会。几何剪影完全不变，只是光影骗眼睛。
- ❌ **「法线贴图分辨率越高越好」**：法线是方向数据，边缘信息比分辨率更重要；1024 通常足够，过高浪费性能。
- ❌ **「法线贴图可以直接从照片生成」**：一般需要烘焙（从高模）或从高度图转换，照片直接转出来的法线质量很差。
- ❌ **「法线贴图和置换贴图是一回事」**：法线只骗光影，置换真的移动顶点（剪影会变），成本高很多。
- ❌ **「翻转绿通道等于降低强度」**：翻绿是修正方向约定（DX/GL 标准），降低强度是削弱效果，两回事。

## 游戏引擎导入设置

| 引擎 | 设置 | 说明 |
| ------ | ------ | ------ |
| **Unity** | Texture Type = **Normal Map** | 自动处理 Y 轴翻转；若贴图来自 DirectX 标准，勾选 **Flip Green Channel** |
| **Unreal** | Compression = **Normalmap（BC5/BC7）** | 使用专用法线压缩，自动处理绿通道；导入时选 Normalmap 压缩类型 |

通用规则：

- 引擎里法线贴图一律作为 **Normal / 法线** 类型导入，**不能当普通 RGB 贴图**。
- 若凹凸方向反了（凸变凹），优先**翻转绿色通道（Y）**，而不是去调 Strength。
- 用专用的法线压缩格式（BC5 / BC7 / ASTC），避免 JPG 有损压缩破坏方向数据。

## 进阶：硬边、软边与 MikkTSpace

- **软边（Smooth）**：相邻面法线平滑过渡，法线贴图表现连续、干净。
- **硬边（Sharp）**：相邻面法线方向突变（如盒子边缘），切线不连续，接缝处法线容易「接不上」。
- **建议**：烘焙前给模型设置**自动光滑（Auto Smooth）**（如边角度 `60°`，超过则按硬边处理），能显著减少接缝问题。
- **MikkTSpace**：Blender 与多数引擎默认的切线算法标准。不同软件（Blender、Substance、游戏引擎）若切线算法不一致，会出现接缝。只要导出时都遵循同一标准，就能避免这类问题。

## 相关概念对比

| 贴图类型 | 原理 | 效果 | 成本 |
| --------- | ------ | ------ | ------ |
| **凹凸贴图（Bump）** | 灰度图，仅模拟亮度变化 | 较弱、无真实轮廓 | 最低 |
| **法线贴图（Normal）** | RGB 编码法线方向 | 较好，光影细腻 | 低 |
| **置换贴图（Displacement）** | 真实移动顶点 | 最好，有真实轮廓 | 最高 |
| **视差贴图（Parallax）** | 偏移采样模拟深度 | 介于法线与置换之间 | 中 |
