# 🎨 05-材质与纹理

## 本目录存放什么

让模型「好看」的内容：材质如何设置、纹理如何制作与使用。

## 建议内容

- 材质编辑器与节点：Principled BSDF 原理化材质
- PBR 工作流：Base Color / Roughness / Metallic / Normal 等贴图通道
- 纹理制作：程序化纹理、贴图素材、Substance/在线生成工具
- UV 相关的材质应用（UV 展开本身放 08-UV与烘焙）
- 常见材质：金属、玻璃、皮肤、布料、透明材质
