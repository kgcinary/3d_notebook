# PBR 是什么

PBR（Physically Based Rendering，基于物理的渲染）不是某一种固定的着色器，而是一组用物理规律约束材质和光照的渲染方法。它的目标并不只是“让画面更真实”，而是让材质在不同光照环境中仍然保持合理、稳定、可预测的外观。

传统材质常直接控制“高光有多亮”“阴影是什么颜色”。这些参数容易做出好看的单张画面，但换一套灯光后，材质可能立刻失真。PBR 更倾向于让美术人员描述材料本身：

- 表面是什么颜色；
- 它是金属还是非金属；
- 表面有多粗糙；
- 法线朝向如何变化；
- 是否透明、发光或存在涂层。

渲染器再根据光源、观察方向和物理模型计算最终亮度。PBR 因而更像一套“材质与光照之间的共同语言”。常见实现遵循以下原则：

1. **能量守恒**：表面反射出去的能量不能无缘无故超过接收到的能量。
2. **微表面理论**：宏观看似平整的表面，在微观上由大量朝向不同的小镜面组成。
3. **菲涅尔效应**：反射强度随观察角度变化，越接近掠射角通常越强。
4. **参数具有物理含义**：金属度、粗糙度、折射率等参数应描述材料，而不是某一盏灯下的最终画面。

需要注意：PBR 是对真实光学的实用近似，并不等于逐个模拟所有光子。实时引擎会在画质、速度和美术可控性之间做取舍，不同引擎的具体 BRDF、粗糙度映射和间接光实现也可能不同。

# 人是怎么感知这个世界的材质

人眼并不能直接“看见粗糙度”或“看见金属度”。我们接收到的只是从物体进入眼睛的光，然后由大脑根据一组线索推断材质。

基本过程可以写成：

> 光源发光 → 光与物体相互作用 → 一部分光进入眼睛 → 视觉系统结合环境和经验推断材质

判断材质时最重要的线索包括：

- **高光的大小和清晰度**：窄而清晰的高光通常意味着表面较光滑；宽而模糊的高光通常意味着表面较粗糙。
- **环境反射**：光滑金属会清晰映出周围环境；粗糙金属仍会反射环境，但反射被摊开、变模糊。
- **高光颜色**：多数绝缘体的镜面反射接近光源颜色；金属的镜面反射通常会被材料自身染色。
- **漫反射颜色**：木材、塑料、石头等绝缘体的固有颜色主要来自进入表面后又散射出来的光；纯金属几乎没有通常意义上的漫反射。
- **视角变化**：移动视点时，高光和反射会沿表面移动。动态信息往往比静态颜色更能说明材质。
- **尺度结构**：轮廓、凹凸、划痕、孔隙和纤维方向会共同影响判断。法线、粗糙度与几何细节必须在尺度上相互匹配。
- **光照环境**：材质不能脱离环境单独存在。没有可供反射的亮暗结构，再光滑的金属也可能显得暗淡甚至接近黑色。

因此，“颜色像金属”并不足以构成金属感。金属感通常来自彩色镜面反射、极弱的漫反射、合理的粗糙度，以及能够被反射出来的环境。

# 金属度工作流和高光工作流

PBR 材质常见两种参数化方式。它们可以表达相近的材质，但贴图含义不同，不能直接混用。

| 工作流 | 主要贴图 | 核心思路 | 优点 | 容易出错的地方 |
| --- | --- | --- | --- | --- |
| 金属度/粗糙度（Metallic/Roughness） | Base Color、Metallic、Roughness | 先判断表面是不是金属，再由基础色决定漫反射色或金属反射色 | 参数少、直观、跨引擎常见、不容易产生明显不合理的材质 | 容易把金属度误当成光滑度；对特殊绝缘体的 F0 控制较少 |
| 镜面反射/光泽度（Specular/Glossiness） | Diffuse、Specular、Glossiness | 分别指定漫反射颜色和镜面反射颜色/强度 | 对镜面颜色和非金属 F0 控制更直接 | 更容易让漫反射与镜面反射之和违反能量守恒 |

Glossiness（光泽度）在许多约定中与 Roughness（粗糙度）方向相反：

$$
\text{Glossiness} \approx 1-\text{Roughness}
$$

但不同软件可能使用不同曲线或通道，转换时应查看目标引擎规范，不能只凭贴图看起来相反就直接翻转。

# 初讲金属度工作流

金属度工作流通常以三张核心贴图描述表面：基础色、金属度和粗糙度。法线、环境光遮蔽、高度、自发光、透明度等贴图可以继续补充细节，但不改变这三个参数的基本分工。

## 粗糙度贴图

粗糙度描述微观表面法线分布得有多散，而不是物体轮廓有多凹凸。

- `0` 或黑色：微表面朝向比较一致，反射集中，像镜面一样清晰。
- `1` 或白色：微表面朝向分散，反射覆盖范围更广，看起来更模糊。

粗糙度主要改变反射能量在方向上的分布。表面变粗糙时，高光会变宽、峰值会降低，但不应被理解为“反射能量凭空消失”。实际实时 BRDF 因为省略微表面之间的多次反射，可能还会进行近似或能量补偿。

制作粗糙度贴图时应注意：

- 指纹、油污和抛光通常改变的是粗糙度，不一定改变基础色。
- 划痕可能同时影响法线和粗糙度：划痕形状进入法线，划痕表面的抛光或破损状态进入粗糙度。
- 不要把光源高光或物体阴影画进粗糙度贴图。
- 粗糙度属于数据贴图，应按线性数据读取，不能套用 sRGB 颜色转换。
- 微小噪声并不等于真实细节。粗糙度变化应能解释材料的制造、磨损和污染过程。

粗糙度和法线都在描述表面方向变化，但尺度不同：法线贴图常描述相对较大的纹理起伏，粗糙度则统计更细小、无法逐个表现的微表面变化。

## 金属度贴图

金属度描述当前可见的最外层表面是导体还是绝缘体：

- `0` 或黑色：非金属、绝缘体，例如塑料、木材、石头、玻璃、陶瓷和油漆。
- `1` 或白色：裸露金属，例如铁、铜、金、铝。

真实世界中，大多数均匀材料的金属度接近二值。中间灰度主要用于：

- 金属与非金属交界处的抗锯齿和纹理过滤；
- 像素内同时包含两类材料的混合区域；
- 某些引擎中的艺术化或特殊材质近似。

不要用金属度调节光滑程度，也不要为了“让物体亮一点”而随意增加金属度。以下判断尤其重要：

- **裸露金属**：金属度为 1。
- **喷漆或覆膜的金属**：光首先接触的是油漆、塑料膜或氧化层，因此表层通常按非金属处理。
- **锈迹**：铁锈是氧化物，不是裸露金属，通常按非金属处理。
- **积灰和泥土**：覆盖区域的最外层是灰尘或泥土，也应按非金属处理。
- **掉漆边缘**：漆面区域为 0，露出的金属为 1，过渡像素可因过滤出现灰度。

金属度贴图同样是线性数据贴图。

## 基础色贴图

基础色（Base Color）在金属度工作流中有两种不同含义：

- 对于**非金属**，它主要表示材料的漫反射颜色，也就是光进入表面、被吸收和散射后重新离开表面的颜色。
- 对于**金属**，它表示有颜色的镜面反射率，近似对应正入射时的反射颜色 $F_0$。此时通常不再保留普通漫反射分量。

因此，同一张 Base Color 贴图在金属度为 0 和 1 的区域会被着色器用在不同位置。

制作基础色贴图时：

- 不应烘焙固定光源造成的高光、投影或环境明暗，否则换灯光后会重复受光。
- 环境光遮蔽通常单独存放，不应直接混进基础色；除非目标项目明确采用这种美术管线。
- 基础色通常作为 sRGB 颜色纹理存储，着色器采样后应转换到线性空间再参与光照计算。
- 应描述材料本身的反射颜色，而不是直接复制一张带完整光照的照片。

### RGB、色相、明暗和饱和度

RGB 是用红、绿、蓝三个分量编码颜色的方法；色相、饱和度、明度则是另一种更接近美术调色习惯的描述。二者有关联，但不能简单对应为三个独立的物理属性。

- **色相**：颜色大致属于红、黄、绿、蓝中的哪一类。
- **饱和度**：颜色离中性灰有多远。
- **明度/亮度**：颜色在视觉上有多亮。HSV 中的 Value 只是 RGB 最大分量，不等同于真实感知亮度，也不等同于物理反射率。

PBR 计算尤其要区分 **sRGB 数值** 与 **线性 RGB 数值**。图片编辑器里看到的中灰数值，并不代表线性空间中反射了一半能量。颜色贴图通常以 sRGB 编码保存；金属度、粗糙度、法线和 AO 等数据贴图则应按线性数据读取。

## 金属度、粗糙度和基础色的关系

可以先记住下面这张表：

| 材质属性 | 非金属 | 金属 |
| --- | --- | --- |
| Metallic | 0 | 1 |
| Base Color 的意义 | 漫反射颜色 | 正入射镜面反射颜色，近似 $F_0$ |
| 普通漫反射 | 有 | 近似为 0 |
| 镜面反射颜色 | 通常接近无色，主要呈现光源/环境颜色 | 由金属本身染色 |
| 默认 $F_0$ | 常用约 0.04 的线性反射率 | 由 Base Color 提供，通常更高且有颜色 |
| Roughness | 独立决定高光宽窄 | 同样独立决定反射清晰度 |

在一个常见的简化实现中：

$$
F_0=\operatorname{lerp}(0.04,\ \text{BaseColor},\ \text{Metallic})
$$

$$
\text{DiffuseColor}=\text{BaseColor}\,(1-\text{Metallic})
$$

这说明：金属度升高时，基础色逐渐从漫反射通道转移到镜面反射通道。具体引擎可能允许通过 IOR、Specular 或 Reflectance 参数修改非金属的 $F_0$，所以 `0.04` 是常见默认值，不是所有绝缘材料都严格相同。

### 反射率

反射率表示入射光中有多少比例被反射。它是能量比例，不等同于屏幕上的像素亮度；曝光、光照强度、观察角度、色调映射和显示设备都会改变最终看到的值。

对于空气与折射率为 $\eta$ 的绝缘材料界面，垂直入射时可近似写为：

$$
F_0=\left(\frac{1-\eta}{1+\eta}\right)^2
$$

当 $\eta\approx1.5$ 时，$F_0\approx0.04$，这就是许多实时金属度工作流采用 4% 作为普通非金属默认正入射反射率的原因。

### 金属度贴图（应理解为：非金属—金属）

金属度轴表达的是材料类别，而不是“不太光滑—很光滑”。一个表面可以是：

- 光滑非金属：抛光塑料、清漆、平静水面；
- 粗糙非金属：粉笔、未上釉陶土、粗糙石材；
- 光滑金属：抛光镜面钢、镀铬表面；
- 粗糙金属：喷砂金属、磨砂铝、严重划花的裸露金属。

所以金属度和粗糙度是两个近似正交的维度。

### 粗糙度贴图（应理解为：光滑—粗糙）

粗糙度轴才表达光滑程度。在常见 Roughness 约定中：

- 黑色 `0`：光滑、反射清晰、高光集中；
- 白色 `1`：粗糙、反射模糊、高光分散。

它不判断材料是不是金属。粗糙度相同的金属和塑料会有相似的高光宽度，但高光颜色、漫反射比例和整体能量分布不同。

# 能量守恒

对于不发光的表面，入射光能量最终只能被反射、透射或吸收：

$$
\Phi_{\text{in}}=\Phi_{\text{reflected}}+\Phi_{\text{transmitted}}+\Phi_{\text{absorbed}}
$$

PBR 中的能量守恒意味着 BRDF 不能让表面向所有方向反射出的总能量超过它接收到的能量。镜面反射增强时，能留给漫反射或透射的部分应相应减少。

## 反射

反射可以从外观上分成两部分：

- **镜面反射**：光在表面界面直接反射，方向性强，受菲涅尔和粗糙度影响。
- **漫反射**：光进入非金属内部，经历吸收和多次散射后再次离开表面，方向较分散，并带上材料颜色。

“漫反射”并不是光在一个完美表面上朝所有方向弹开，而通常是次表面散射经过简化后的结果。金属内部会快速吸收进入的电磁波，所以裸金属几乎没有普通漫反射。

## 折射与透射

光从一种介质进入另一种介质时，传播方向会因折射率变化而改变，这叫折射；光穿过物体或表面继续传播叫透射。

常规不透明 Metallic/Roughness 模型通常把透射路径省略掉，因此不能只靠把 Metallic 调低来正确制作玻璃。玻璃、水、薄膜等材质还需要 Transmission、IOR、Thickness、Absorption 等参数或专用 BSDF。

漫反射材质中的光也可能先“透射进表面”，再经过内部散射返回，但这与看穿物体的透明透射不是同一种视觉结果。

## 吸收

没有被反射或透射出去的光会被材料吸收，并通常转化为热。材料对不同波长的吸收能力不同，于是产生颜色：

- 红色塑料更多地把红色波段散射出来，同时吸收其他波段；
- 金会对不同可见光波段产生不同的镜面反射率，所以反射带有金黄色；
- 有色玻璃的颜色与光在介质内部传播距离有关，厚处往往比薄处吸收更多。

## 金属材料和绝缘材料的视觉差异与物理理论

金属与绝缘体的差异可从电子状态做直观理解：

- **金属/导体**中存在能较自由响应电磁场的电子。进入金属的光会在很短距离内被衰减，表面反射强，而且反射率随波长变化，因此镜面反射可以带颜色。
- **绝缘体/电介质**中的电子更多处于束缚状态。表面仍会发生镜面反射，但通常较弱且接近无色；其余光可以进入内部，被吸收、散射或透射，从而形成有颜色的漫反射或透明效果。

这是一种用于理解材质外观的简化描述。严格计算导体反射时会使用复折射率，其中包含折射率 $\eta$ 与消光系数 $k$。

实践中判断的不是“物体内部是不是金属”，而是**光当前接触到的最外层是什么材料**。一块喷漆钢板的底材是金属，但完整漆面区域首先表现为非金属涂层。

## 微表面理论

微表面模型把宏观表面视为无数微小镜面的集合。每一个微表面都遵循镜面反射定律，但它们的法线方向不同：

- 光滑表面的微法线集中在宏观法线附近，高光窄而清晰；
- 粗糙表面的微法线分布更散，高光宽而模糊；
- 一些微表面会挡住另一些微表面，产生遮蔽和阴影效应。

常见 Cook–Torrance 镜面 BRDF 可以写成：

$$
f_{\text{specular}}=\frac{D\,F\,G}{4(\mathbf n\cdot\mathbf l)(\mathbf n\cdot\mathbf v)}
$$

其中：

- $D$：法线分布函数（NDF），描述有多少微表面朝向半程向量；实时渲染常用 GGX。
- $F$：菲涅尔项，描述界面反射比例如何随角度变化。
- $G$：几何遮蔽项，描述微表面之间的遮挡与自阴影。
- $\mathbf n$、$\mathbf l$、$\mathbf v$：分别是表面法线、入射光方向和观察方向。

许多实时实现会把美术输入的感知粗糙度 $r$ 映射为微表面分布参数 $\alpha=r^2$，使滑块的视觉变化更均匀。但这是常见实现约定，不应假定所有软件都完全相同。

## 全局光照

直接光照只计算光源第一次照到表面的结果；全局光照（GI）还考虑光在场景中的间接反弹。例如红墙会把红色间接光投到旁边的白色物体上。

PBR 材质模型本身不会自动产生全局光照，它仍然需要光照系统提供间接光。常见方案包括：

- 离线或实时光线追踪；
- 烘焙光照贴图、辐照度体积或探针；
- 屏幕空间间接光；
- 基于图像的光照（IBL）和环境立方体贴图。

IBL 对金属尤其重要，因为金属的主要外观来自镜面反射。如果环境图没有亮暗层次，材质即使参数正确，也很难读出金属感。

环境光遮蔽（AO）只近似描述缝隙和接触区域接收环境光的能力，不等同于完整 GI，也不应该粗暴地把所有直接光一起压暗。

## 菲涅尔反射效应

同一种材料的反射率会随观察角度改变。正对表面观察时反射相对较弱；视线接近表面切线，也就是掠射角时，反射趋向增强。这就是菲涅尔效应。

实时渲染常使用 Schlick 近似：

$$
F(\theta)=F_0+(1-F_0)(1-\cos\theta)^5
$$

这里的角度通常由观察方向与微表面半程向量计算。公式表达了两个关键现象：

1. 正入射时反射率接近 $F_0$；
2. 接近掠射角时反射率趋向 1。

粗糙度不会直接改变材料本征的 $F_0$，但会改变哪些微表面方向参与反射，所以最终高光形状和强度分布会明显变化。

### F0

$F_0$ 是光线垂直入射表面时的菲涅尔反射率，也叫正入射反射率。

- 普通绝缘体常落在约 2%～5% 的范围，实时引擎经常默认使用 4%。
- 金属的 $F_0$ 通常更高并且带颜色，在金属度工作流里由 Base Color 提供。
- $F_0$ 不是“高光亮度随便调节器”，它应来自材料的折射率或测量反射数据。

### 基础色、金属度、粗糙度的关联

可以用以下顺序判断一个像素：

1. **最外层是不是裸露金属？** 用 Metallic 回答。
2. **材料反射什么颜色？** 非金属时 Base Color 进入漫反射；金属时 Base Color 进入 $F_0$。
3. **反射有多集中？** 用 Roughness 控制微表面分布。
4. **表面朝向怎样变化？** 用几何法线和法线贴图控制。
5. **周围有什么可以被反射？** 由直接灯光、GI、反射探针或环境图提供。

一个简洁但非常重要的结论是：

> Metallic 决定反射属于哪类材料，Base Color 决定反射或散射的颜色，Roughness 决定这些反射在方向上有多分散。

# PBR 的计算机运行原理

渲染器最终要计算的是：从某个表面点沿观察方向离开的光有多少。渲染方程的简化形式为：

$$
L_o(\mathbf p,\mathbf v)=L_e+\int_{\Omega} f_r(\mathbf l,\mathbf v)\,L_i(\mathbf p,\mathbf l)\,(\mathbf n\cdot\mathbf l)\,d\mathbf l
$$

- $L_o$：离开表面、进入相机的光；
- $L_e$：表面自身发出的光；
- $L_i$：从某个方向到达表面的光；
- $f_r$：BRDF，描述材料如何把入射光反射到观察方向；
- $\mathbf n\cdot\mathbf l$：光线与表面夹角造成的余弦衰减。

实时引擎通常不会完整求解这个积分，而是把它拆成有限光源、阴影、环境光和预计算数据。一个典型运行流程如下：

1. **处理几何**：将模型顶点从模型空间变换到世界空间和裁剪空间，插值得到每个像素的位置、UV、法线和切线。
2. **采样贴图**：读取 Base Color、Metallic、Roughness、Normal、AO 等纹理。
3. **处理颜色空间**：Base Color 从 sRGB 解码到线性空间；金属度、粗糙度、法线和 AO 作为线性数据使用。
4. **重建表面参数**：使用法线贴图修正法线，计算 $F_0$、漫反射颜色和微表面粗糙度参数。
5. **计算直接光**：对每盏灯求光线方向、衰减、阴影，再计算漫反射 BRDF 与 Cook–Torrance 镜面 BRDF。
6. **计算间接光**：使用光照贴图、探针、IBL 或实时 GI。常见 IBL 会分别计算低频漫反射辐照度和经过粗糙度预过滤的镜面环境反射。
7. **累加能量**：将直接光、间接光和自发光相加；透明材质还要处理透射、折射和背景合成。
8. **输出显示**：在线性 HDR 空间完成曝光与色调映射，再编码为显示器需要的 sRGB 或其他输出色彩空间。

下面是一段帮助理解的伪代码，并不对应所有引擎的完整实现：

```glsl
vec3 baseColor = SRGBToLinear(sampleBaseColor());
float metallic = sampleMetallic();
float roughness = sampleRoughness();

vec3 F0 = mix(vec3(0.04), baseColor, metallic);
vec3 diffuseColor = baseColor * (1.0 - metallic);
float alpha = roughness * roughness;

vec3 F = FresnelSchlick(F0, VdotH);
float D = DistributionGGX(alpha, NdotH);
float G = GeometrySmith(alpha, NdotV, NdotL);

vec3 specularBRDF = D * G * F / max(4.0 * NdotV * NdotL, epsilon);
vec3 diffuseBRDF = (1.0 - F) * diffuseColor / PI;
vec3 outgoingLight = (diffuseBRDF + specularBRDF) * lightRadiance * NdotL;
```

实际引擎还会处理多重散射补偿、多层材质、各向异性、清漆、次表面散射、透射、阴影滤波、抗锯齿和降噪等问题。

延迟渲染通常先把 Base Color、法线、金属度和粗糙度写入 G-buffer，再集中计算光照；前向渲染则在绘制物体时直接完成材质与光照计算。两者改变的是数据组织和性能权衡，并不改变 PBR 参数的基本物理含义。

## 常用贴图与色彩空间速查

| 贴图 | 常见内容 | 一般读取方式 |
| --- | --- | --- |
| Base Color / Albedo | 非金属漫反射色或金属 $F_0$ 颜色 | sRGB 颜色纹理，采样后转线性 |
| Metallic | 非金属 0、金属 1 | 线性数据 |
| Roughness | 光滑 0、粗糙 1 | 线性数据 |
| Normal | 切线空间法线方向 | 线性数据，采样后解码向量 |
| Ambient Occlusion | 间接环境光可见程度 | 线性数据 |
| Emissive | 自发光颜色 | 通常按颜色纹理处理，再在线性空间参与计算 |

通道打包依项目规范而定。例如 glTF 2.0 的 Metallic-Roughness 纹理使用 G 通道存 Roughness、B 通道存 Metallic；一些引擎常用 ORM 贴图，将 AO、Roughness、Metallic 分别放入 R、G、B。导入资产前必须确认通道约定。

## 材质制作检查清单

- 金属度是否在回答“最外层是不是裸露金属”，而不是回答亮不亮或滑不滑？
- 粗糙度是否有材料成因，而不是覆盖一层均匀随机噪声？
- 基础色中是否混入了固定高光、阴影或 AO？
- Base Color 是否按 sRGB 读取，数据贴图是否按线性读取？
- 涂层、锈迹、灰尘和油污是否按最外层材质处理？
- 金属是否有足够丰富的环境可供反射？
- 法线细节和粗糙度细节是否处在合理尺度？
- 观察材质时是否使用了中性 HDRI、灰球/镜面球和不同曝光条件进行交叉检查？
- 从一种软件导入另一种软件时，是否核对了 Roughness/Glossiness 方向及通道打包规则？
