# 📚 11-资源与参考

## 本目录存放什么

学习过程中的参考资料库：速查表、插件、网站、素材。

## 建议内容

- `快捷键速查表.md` — 按分类整理的 Blender 常用快捷键
- `插件清单.md` — 已安装/想安装的插件、用途、安装方式
- `参考网站.md` — 教程网站、官方文档、社区（B站、YouTube、Blender 官网、Blenderartists 等）
- `素材收集.md` — HDRI、贴图素材、模型库的来源链接
- `术语表.md` —（也可放在 01-基础概念，二选一）

## 笔记命名规范

`11-资源与参考/名称.md`，例如 `01-快捷键速查表.md`、`02-插件清单.md`

所有笔记都是 Markdown 文件，链接直接粘贴 URL 即可。
