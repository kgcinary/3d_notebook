## 📝 使用指南

1. **按主题存放**：笔记放进对应主题目录，目录内先放一个说明文件（`说明.md`），说明该目录的用途和命名规范。
2. **笔记命名**：建议 `主题-序号-名称.md`，例如 `01-基础概念/01-什么是网格拓扑.md`；序号方便按学习顺序排序。
3. **笔记结构**：推荐包含「核心概念 → 操作步骤 → 关键参数 → 踩坑记录 → 参考链接」几个部分。
4. **项目积累**：每个练习项目在 `10-项目实战` 下建一个子目录，放过程笔记、截图和成品参考。
5. **边学边记**：遇到新知识点随手记录，不要等「学完了」再整理——知识库是越用越厚的。
